# Amazon 图片工作室快速开始

## 一句话规则

一个窗口只处理一个 SKU。需要同时制作多个商品时，新建或复制多个 Codex 任务，每个任务分别上传一个 SKU 的商品资料和参考图，让它们并行运行。

## 可以做什么

- 为一个 SKU 制作 Amazon Listing 图片集
- 为一个 SKU 制作 A+ 页面模块
- 只做图片方案、Prompt 和合规检查
- 先确认一个 SKU 的风格，再在其他窗口使用相同的风格预置

## 最短使用流程

1. 在 Codex 中新建一个任务。
2. 点击底部消息输入框，粘贴下面的任务模板。
3. 填入当前商品的标题、五点描述和可选补充资料。
4. 将当前 SKU 的参考图拖入消息输入框后发送。
5. 先确认数量、尺寸和推荐配色，再查看方案并生成图片。
6. 处理其他商品时，为每个 SKU 新建一个独立任务并重复以上流程。

## Prompt 旁边的模板图片

发送商品标题、描述和参考图后，Codex 会在首次确认图片数量、尺寸时展示配色模板，并主动提醒：如果没有喜欢的配色模板，也可以在这一步上传一张喜欢配色的图片。AI 会提取主色、辅助色和点缀色，作为整套 Listing 附图和 A+ 图片的配色参考。只借鉴配色，产品本身颜色保持不变，`MAIN` 主图仍用纯白背景。上传配色图是可选项，仍可直接选择内置模板。

生成图片 Prompt 方案时，Codex 会同步展示全部已安装的风格模板图，并用中文名称和中文说明标注。你可以直接回复序号或中文名称，例如“1”“清爽科技”或“高级对比”，不需要理解或输入英文模板 ID。未指定风格时，默认使用系统根据产品推荐的配色模板。如果模板图无法显示，Codex 会改为列出完整的中文模板选项。

图片信息密度也可以选择：`minimal`（简约，默认）或 `rich`（内容丰富）。你可以直接回复“简约”或“内容丰富”。

确认模板后，后续 Listing 附图和 A+ 图片会使用同一张模板图作为风格参考，保持整套图片的视觉一致性。Amazon Listing `MAIN` 主图仍然使用纯白背景，不使用风格模板图。

## 可直接粘贴的任务模板

上传少量产品参考图，再发送以下资料即可。需要时可输入 `$amazon-image-studio` 调用；SKU、市场和任务类型有明确要求时再补充。

```text
产品标题：[粘贴标题]
产品五点描述：[粘贴五点描述]
补充：[尺寸、颜色等，没有可省略]
```

## Codex 菜单里的“复制”怎么用

- **复制工作目录**：复制项目文件夹路径，可粘贴到资源管理器地址栏；不会复制任务。
- **复制深度链接**：复制当前任务链接，可粘贴到浏览器地址栏或发给别人；不会创建独立 SKU 任务。
- **复制为 Markdown**：复制当前对话文字，可粘贴到新任务底部的消息输入框。
- **在新窗口中打开**：打开当前任务的另一个窗口。要让不同 SKU 完全隔离，优先使用“新建任务”，再粘贴上面的模板。

## 最短提问方式

用户也可以直接说：

```text
请为这个 SKU 制作 Amazon US Listing 图片。我会上传商品资料和参考图，先给我方案，再生成 7 张图。
```

如果用户有多个 SKU，应提醒：每个窗口只放一个 SKU；复制任务模板后替换 SKU 和参考图即可并行处理。
