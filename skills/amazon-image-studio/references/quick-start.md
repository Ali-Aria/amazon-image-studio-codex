# Amazon 图片工作室快速开始

## 一句话规则

一个窗口只处理一个 SKU。需要同时制作多个商品时，新建或复制多个 Codex 任务，每个任务分别上传一个 SKU 的商品资料和参考图，让它们并行运行。

## 可以做什么

- 为一个 SKU 制作 Amazon Listing 图片集
- 为一个 SKU 制作 A+ 页面模块
- 只做图片方案、Prompt 和合规检查
- 先确认一个 SKU 的风格，再在其他窗口使用相同的风格预置

## 最短使用流程

1. 在 Codex 中新建一个任务。
2. 点击底部消息输入框，粘贴下面的任务模板。
3. 把模板中的 SKU、商品资料替换成当前商品。
4. 将当前 SKU 的参考图拖入消息输入框后发送。
5. 先确认图片方案和视觉风格，再让 Codex 生成图片。
6. 处理其他商品时，为每个 SKU 新建一个独立任务并重复以上流程。

## Prompt 旁边的模板图片

生成图片 Prompt 方案时，Codex 会同步展示全部已安装的风格模板图，并用中文名称和中文说明标注。你可以直接回复序号或中文名称，例如“1”“清爽科技”或“高级对比”，不需要理解或输入英文模板 ID。未选择时默认推荐“清爽科技”。如果模板图无法显示，Codex 会改为列出完整的中文模板选项。

图片信息密度也可以选择：`minimal`（简约，默认）或 `rich`（内容丰富）。你可以直接回复“简约”或“内容丰富”，也可以在任务模板中修改 `图片信息密度`。

确认模板后，后续 Listing 附图和 A+ 图片会使用同一张模板图作为风格参考，保持整套图片的视觉一致性。Amazon Listing `MAIN` 主图仍然使用纯白背景，不使用风格模板图。

## 可直接粘贴的任务模板

```text
$amazon-image-studio

请只处理一个 SKU。

SKU：SKU001
市场：Amazon US
任务：Listing 图片
图片数量：7 张
视觉风格：clean-tech
图片信息密度：minimal（简约，默认；如需更多信息可改为 rich／内容丰富）

商品标题：
[粘贴标题]

五点描述：
[粘贴五点]

其他资料：
[粘贴商品描述、尺寸、材质、包装内容等]

我已上传该 SKU 的参考图。

要求：
- 严格依据商品资料和参考图，不要虚构产品功能、尺寸、材质或认证
- 先输出图片方案、待核实问题和 Prompt
- 确认后再生成图片
- 所有文件使用 SKU001 作为前缀
```

## Codex 菜单里的“复制”怎么用

- **复制工作目录**：复制项目文件夹路径，可粘贴到资源管理器地址栏；不会复制任务。
- **复制深度链接**：复制当前任务链接，可粘贴到浏览器地址栏或发给别人；不会创建独立 SKU 任务。
- **复制为 Markdown**：复制当前对话文字，可粘贴到新任务底部的消息输入框。
- **在新窗口中打开**：打开当前任务的另一个窗口。要让不同 SKU 完全隔离，优先使用“新建任务”，再粘贴上面的模板。

## 最短提问方式

用户也可以直接说：

```text
请为这个 SKU 制作 Amazon US Listing 图片。我会上传商品资料和参考图，先给我方案，再生成 7 张图。
```

如果用户有多个 SKU，应提醒：每个窗口只放一个 SKU；复制任务模板后替换 SKU 和参考图即可并行处理。
